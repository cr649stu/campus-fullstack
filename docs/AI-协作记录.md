## 4. 智能体执行的典型指令

```bash
# 安装依赖
pnpm install

# 启动接口（Express + SQLite）
node server/src/index.js

# 接口冒烟测试：发文、点赞、评论、提问、回答、采纳、购物袋、下单、取消
node scripts/test-api.mjs

# 无头浏览器截图（CDP）
node scripts/shoot.mjs screenshots

# 生成 Word 截图文档
python scripts/build_screenshot_docx.py
```

## 5. 产出与验证

- **代码**：`server/`（Express + SQLite，12 张表、30+ 接口）、`web/`（React 19 + TS，17 个页面）。
- **测试**：`scripts/test-api.mjs` 覆盖 15 项写操作，全部通过；页面截图过程无 JS 报错。
- **文档**：`毕业之前-运行截图.docx` 共 26 页（封面、项目说明、截图目录、23 页截图）。
- **版本控制**：Git 提交历史按「工程配置 → 认证 → 业务接口 → 示例数据 → 前端壳 → 页面 → 样式 → 测试 → 文档 → CI」拆分，便于查看开发过程。

## 6. 人工参与部分

1. 选择项目范围、内容主题、加分功能与视觉风格（见第 2 节）。
2. 确认「三个项目合并为一个站点」的呈现方式。
3. 验收运行截图与 Word 排版，提出把截图汇总为一个 Word 的追加要求。
4. 提供 GitHub 仓库与推送凭据，完成远程仓库提交。
